# Student Registration System

Приложение для автоматизации процесса регистрации и учета студентов.

## Описание
Система позволяет вести базу данных студентов, добавлять новые записи, редактировать существующую информацию и осуществлять поиск по заданным критериям. 

## Функционал
* Добавление, редактирование и удаление записей о студентах.
* Поиск и фильтрация данных.
* Валидация вводимых данных (проверка на корректность).
* Удобный пользовательский интерфейс.

## Стек технологий
* **Язык:** C#
* **База данных:** 
* **UI:** Windows Forms / WPF
* **Технологии:** ADO.NET / Entity Framework 

## Инструкция по запуску
1. Склонируйте репозиторий.
2. Разверните базу данных
4. Откройте решение в Visual Studio.
5. Настройте строку подключения к вашей БД в конфигурационном файле.
6. Запустите проект.
