# 🎓 Student Registration System

**Desktop-приложение для автоматизации процесса регистрации и учета студентов.**

Проект реализован на современной платформе .NET 8 с использованием Windows Forms. Основная цель — создание удобного инструмента для работы с базой данных студентов, обеспечивающего высокую скорость ввода и валидацию информации.
---

## 🛠 Стек технологий
*   **Язык:** C#
*   **Платформа:** .NET 8.0 (Windows Forms)
*   **Среда разработки:** Visual Studio 2022
*   **Архитектура:** ООП (разделение логики интерфейса и данных)

---

## ✨ Ключевой функционал
*   **Регистрация студентов:** Добавление новых записей с валидацией вводимых данных.
*   **Управление записями:** Редактирование и удаление информации о студентах.
*   **Просмотр данных:** Удобное отображение списка студентов (таблица/карточки).
*   **Поиск и фильтрация:** Быстрый доступ к нужной записи по ключевым полям.

---

## 🏗 Структура проекта
*   `StudentRegistration.sln` — файл решения для Visual Studio.
*   `StudentRegistration/` — папка с основным проектом:
    *   `Program.cs` — точка входа, настройка конфигурации приложения (High DPI, стили).
    *   `Form1.cs` — основная логика работы с формой и обработчики событий.
    *   `Form1.Designer.cs` — автоматически сгенерированный код для UI-элементов.
